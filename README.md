# Fahri Aybars Barut — C64 3D Portfolio

An immersive Commodore 64-inspired 3D portfolio for **Fahri Aybars Barut**, a Computer Engineer and Simulation & VR/XR Developer.

## Live Website

[https://aybarsbarut.com.tr/](https://aybarsbarut.com.tr/)

Main portfolio: [https://aybarsbarut.com/](https://aybarsbarut.com/)

## Experience

- Photorealistic interactive 1980s desk scene built with React Three Fiber.
- Functional CRT interface with C64-style navigation and boot sequence.
- Portfolio sections for background, projects, certifications and contact links.
- Interactive keyboard, notebook CV, cassette audio and hidden easter eggs.
- Desktop-first 3D experience with mobile visitors redirected to the main portfolio.

## Technology

Next.js 16, React 19, TypeScript, Three.js, React Three Fiber, Drei, Zustand, GSAP and Howler.

## SEO

The site includes canonical metadata, Open Graph and Twitter previews, a custom C64 favicon, `ProfilePage`/`Person` structured data, `robots.txt`, and `sitemap.xml`.
